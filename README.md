# DeskMate v2 - Windows 바탕화면 멀티플레이어 캐릭터 코워킹 & 채팅

**React + Electron + Socket.io + Supabase** 기반의 Windows 바탕화면 멀티플레이어 캐릭터 채팅 및 코워킹 데스크톱 애플리케이션입니다.

---

## 1. 주요 기능 (v2 확장 완료)

### ① 캐릭터 상호작용 & 애니메이션 고도화
- **감정 표현(이모트) 및 액션 제스처**: 인사(`👋`), 점프(`⭐`), 춤추기(`🎵`), 하트(`❤️`), 잠자기(`💤`) 모션 및 단축키(`Alt+1` ~ `Alt+5`)
- **물리 효과 (중력 & 작업표시줄 착지)**: 내 캐릭터를 높은 곳으로 드래그해서 놓으면 중력 가속도와 탄성 바운스로 작업표시줄 위 바닥에 통통 튀며 착지
- **타 유저 캐릭터와 상호작용**: 바탕화면에서 다른 유저의 캐릭터를 클릭하면 `🫳 쓰다듬기`, `👉 찌르기`, `🙌 하이파이브` 리액션 전송

### ② 데스크톱 편의성 & 코워킹 기능
- **바탕화면 미니 채팅 입력바 (Quick Chat)**: 내 캐릭터 **더블클릭** 또는 글로벌 단축키 **`Alt + Enter`**로 캐릭터 바로 위에 미니 채팅창 호출
- **시스템 트레이(System Tray) & 단축키 제어**: 메인 창 닫기 시 트레이 상주, 트레이 우클릭 메뉴 및 **`Alt + H`**로 오버레이 숨김/보이기, **방해 금지 모드(DND)** 전환
- **함께 집중하기 (포모도로 타이머 & 상태 표시)**: 캐릭터 닉네임 옆 상태 배지(`🔥 코딩 중`, `☕ 휴식 중`, `🎧 회의 중`, `🍅 집중 중`) 및 방 공유 **25분 집중 / 5분 휴식 포모도로 타이머**
- **다중 모니터(Multi-Monitor) 선택**: 연결된 모니터 목록을 조회하고 원하는 모니터로 오버레이 창 즉시 이동

### ③ 멀티플레이어 방(Room) & 채팅 확장
- **비밀방(비밀번호) 및 6자리 초대 코드**: 비밀방 생성/입장 검증 및 초대 코드로 즉시 입장
- **방 목록 & 채팅 기록(History) Supabase DB 연동**: Supabase `users`, `rooms`, `messages` 테이블 연동으로 늦게 입장한 유저도 이전 대화(최대 50개) 확인 가능
- **효과음(SFX) 및 말풍선 알림음**: Web Audio API 기반 말풍선 팝업음, 캐릭터별 사운드, 이모트/미니게임 효과음 및 음소거(Mute) 옵션
- **소셜 미니 게임**: 채팅창에 `/주사위` (`/dice`), `/가위바위보` (`/rps`, `/가위`, `/바위`, `/보`) 입력 또는 버튼 클릭으로 주사위 굴림 & 가위바위보 대결

## 2. 단축키 안내
| 단축키 | 동작 |
| :--- | :--- |
| **`Alt + Enter`** (또는 내 캐릭터 더블클릭) | 바탕화면 캐릭터 위 **미니 채팅 입력바 (Quick Chat)** 열기 |
| **`Alt + H`** | 바탕화면 오버레이 잠시 숨기기 / 다시 보이기 토글 |
| **`Alt + 1 ~ 5`** | 감정 표현(인사, 점프, 춤추기, 하트, 잠자기) 즉시 실행 |
| **`Esc`** | 바탕화면 미니 채팅 입력바 닫기 |

## 3. 실행 및 Supabase 설정

1. Supabase SQL Editor에서 [server/schema.sql](file:///c:/project/DeskMate/server/schema.sql)을 실행하면 `users`, `rooms`, `messages` 3개 테이블이 생성되어 영구 DB 저장이 활성화됩니다.
2. 통합 개발 실행:
   ```powershell
   npm run dev
   ```
