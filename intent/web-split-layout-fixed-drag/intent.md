# 작업 의도 정의서 (Intent): 순수 웹 기반 대화방 좌·우 2분할 레이아웃 전환 및 캐릭터 드래그 위치 고정

## 1. 작업 목적
Electron 데스크톱 앱 실행 방식을 사용하지 않고 **웹 브라우저(Vercel 등) 자체에서 모든 기능이 완결**되도록 전환하며, 대화방(`CHAT_ROOM`) 하단 영역을 **좌·우 2분할(좌측: 캐릭터가 돌아다니는 스테이지 / 우측: 실시간 채팅방)**로 구성하고, **캐릭터를 마우스로 잡고 이동시켰을 때 아래로 떨어지지 않고 이동된 위치 그대로 고정**되도록 개선합니다.

---

## 2. 배경 및 필요성
1. **Electron 실행 의존성 제거 및 웹 단일 화면 완결성 확보**:
   - 외부 프로그램(`Electron을 여시겠습니까?`, `deskmate://` 프로토콜, 로컬 브릿지 호출 등)을 띄우지 않고, 웹 브라우저 화면 안에서 곧바로 캐릭터 활동과 채팅을 동시에 즐길 수 있는 직관적인 구조가 필요합니다.
2. **대화방 하단 좌·우 2분할(Split View) 레이아웃 요구**:
   - 대화방 진입 시 하단 영역을 좌·우 2분할로 배치하여 **좌측에는 캐릭터들이 돌아다니고 상호작용하는 전용 공간**, **우측에는 실시간 채팅 메시지 목록 및 입력창**이 나란히 보이도록 구성해야 합니다.
3. **캐릭터 드래그 이동 후 중력 낙하 제거 및 위치 고정 요구**:
   - 기존에는 캐릭터를 마우스로 드래그하여 원하는 위치(공중이나 상·중·하단 원하는 지점)에 놓으면 중력 물리 엔진(`startGravityDrop`)이 작동해 바닥(`y = 88%`)으로 강제 낙하시켰습니다.
   - 사용자의 요청에 따라 캐릭터를 잡고 이동시켰을 때 **아래로 떨어뜨리지 않고 이동된 좌표(`x, y`) 상태 그대로 고정**되어야 합니다.

---

## 3. 기대 효과 / 해결 목표
1. **Electron 관련 호출·버튼 완전 제거**:
   - 웹 접속 시 자동 `deskmate://open` 팝업, 방 입장 시 `deskmate://enter-room` 호출 및 Electron 열기 버튼을 모두 제거하여 깔끔한 순수 웹 애플리케이션으로 동작합니다.
2. **한눈에 보이는 대화방 좌·우 2분할(좌: 캐릭터 란 / 우: 채팅방) UI**:
   - 좌측 캐릭터 스테이지에서 Rive 동물 캐릭터들의 움직임·말풍선·이모트·상호작용을 보면서, 동시에 우측 채팅방에서 편리하게 대화를 나눌 수 있습니다.
3. **캐릭터 드래그 위치 그대로 고정 유지**:
   - 마우스로 내 캐릭터를 잡고 원하는 위치로 옮겨 놓으면 아래로 떨어지지 않고 해당 위치(`x, y`)에 그대로 고정되며, 다른 참여자들에게도 고정된 위치가 실시간으로 동기화됩니다.
