# 작업 의도 정의서 (Intent): 채팅 입력란 상단 버튼 선택 시 채팅 입력란 자동 닫기

## 1. 작업 목적
채팅 입력창(`Quick Chat`)이 열려 있을 때 **입력란 상단의 액션 버튼(이모트 👋·⭐·🎵·❤️·💤 및 미니게임 🎲·✌️)을 선택하면 즉시 채팅 입력란이 닫히도록(없어지도록)** 개선합니다.

---

## 2. 배경 및 필요성
- 현재 미니 채팅 입력창 상단에는 5종의 이모트 버튼(`👋`, `⭐`, `🎵`, `❤️`, `💤`)과 2종의 미니게임 버튼(`🎲`, `✌️`)이 배치되어 있습니다.
- 이 중 이모트 버튼을 클릭(`handleQuickEmote`)했을 때 이모트는 실행되지만 채팅 입력란이 닫히지 않고 화면에 그대로 남아 있어, 버튼 선택 즉시 입력란이 깔끔하게 사라지도록 동작을 통일할 필요가 있습니다.

---

## 3. 기대 효과 / 해결 목표
- 채팅 입력창 상단의 어떤 버튼(이모트 5종 및 미니게임 2종)을 클릭하더라도 **선택한 동작이 즉시 실행됨과 동시에 채팅 입력란이 자동으로 닫히고**, 포커스가 다시 캐릭터 월드로 돌아와 방향키 이동을 바로 이어갈 수 있습니다.
