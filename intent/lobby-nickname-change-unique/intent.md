# 작업 의도 정의서 (Intent): 방 목록(로비) 화면 닉네임 변경 기능 추가 및 닉네임 중복 불가 처리

## 1. 작업 목적
방 목록 화면(`LOBBY`)에서 사용자가 **자신의 닉네임을 직접 변경**할 수 있도록 UI와 API를 추가하고, **회원가입 및 닉네임 변경 시 이미 다른 사용자가 사용 중인 닉네임은 사용할 수 없도록(중복 불가능)** 검증 로직을 적용합니다.

---

## 2. 배경 및 필요성
1. **방 목록 화면에서 닉네임 변경 기능 필요**:
   - 현재 방 목록(`LOBBY`) 화면에서는 캐릭터 변경 및 초기화만 가능하고 닉네임을 수정할 수 있는 기능이 없어, 계정을 새로 만들지 않고도 원하는 닉네임으로 변경할 수 있는 UI가 필요합니다.
2. **닉네임 중복 방지(Unique) 필요**:
   - 캐릭터 월드에서 참여자들을 닉네임으로 식별하므로, 동일한 닉네임을 여러 명이 중복 사용하면 혼선이 발생합니다.
   - 따라서 **닉네임 변경 시**뿐만 아니라 **신규 회원가입 시**에도 기존 사용자들의 닉네임과 중복되는지 검사하여 중복을 원천 차단해야 합니다.

---

## 3. 기대 효과 / 해결 목표
1. **방 목록(로비)에서 간편한 닉네임 변경**:
   - 방 목록 상단 프로필 영역에서 `[닉네임 변경]` 버튼을 눌러 새 닉네임을 입력·저장하면 즉시 DB(Supabase / 로컬 스토리지)와 화면에 반영됩니다.
2. **닉네임 중복 완벽 차단**:
   - 다른 사용자가 이미 사용 중인 닉네임으로 변경하거나 회원가입을 시도할 경우 `"이미 사용 중인 닉네임입니다."` 안내 메시지를 표시하고 저장을 차단하여 모든 사용자의 닉네임 고유성을 보장합니다.
