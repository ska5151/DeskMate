# 작업 의도 정의서 (Intent): 캐릭터 월드 내 채팅 입력란 상단 중복 버튼들 삭제

## 1. 작업 목적
캐릭터 월드 안에서 `[💬 채팅 입력]` 버튼을 눌렀을 때 열리는 미니 채팅 입력창(`Quick Chat`) 상단의 **이모트 및 미니게임 버튼 줄(`.quickchat-action-strip`)을 삭제**하고, 순수하게 채팅 메시지 입력란과 전송/닫기 버튼만 표시되도록 간소화합니다.

---

## 2. 배경 및 필요성
- 이미 캐릭터 월드 상단 바(`.action-bar-row`)에 이모트 5종(`👋 인사`, `⭐ 점프`, `🎵 춤추기`, `❤️ 하트`, `💤 잠자기`)과 미니게임 2종(`🎲 주사위`, `✌️ 가위바위보`) 버튼이 모두 배치되어 있습니다.
- 따라서 캐릭터 월드 내부의 채팅 입력란 위에 동일한 버튼들이 중복으로 표시될 필요가 없으므로 이를 제거하여 입력창 UI를 깔끔하게 정리합니다.

---

## 3. 기대 효과 / 해결 목표
- `[💬 채팅 입력]` 클릭 시 불필요한 중복 아이콘 버튼 없이 **깔끔한 한 줄 채팅 입력창(`input` + `전송` + `✕`)**만 나타나 화면 가림을 최소화하고 직관적인 채팅 입력 경험을 제공합니다.
