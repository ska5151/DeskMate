# 작업 의도 (Intent): 미니게임 말풍선 3초 소멸, 상단 버튼 클릭 시 캐릭터 월드 자동 포커스, 스페이스바 채팅 입력 연동

## 1. 작업 목적
1. **미니게임(주사위, 가위바위보) 말풍선 3초 후 자동 소멸 및 직접 입력 채팅 지속 표시**:
   - 주사위(`🎲`), 가위바위보(`✌️`) 버튼 선택 시 캐릭터 상단에 표시되는 결과 말풍선은 **3초 뒤 자동으로 사라지게** 하고, 사용자가 **직접 입력한 채팅만 계속 유지**되도록 수정합니다.
2. **캐릭터 월드 상단 버튼 선택 시 캐릭터 월드 자동 포커스**:
   - 캐릭터 월드 상단의 버튼(이모트 5종, 주사위, 가위바위보, 포모도로 타이머 버튼 등)을 클릭하면 **자동으로 캐릭터 월드 영역이 포커스**되어, 별도로 캐릭터 월드를 다시 클릭하지 않아도 즉시 **방향키(`↑`, `↓`, `←`, `→`)로 이동**할 수 있도록 수정합니다.
3. **캐릭터 하단 버튼 문구를 `스페이스바`로 변경 및 스페이스바 키 입력 시 채팅 입력란 표시**:
   - 내 캐릭터 닉네임 하단의 `채팅 입력` 표시를 **`스페이스바`**로 변경하고, 키보드 **스페이스바(`Space`)**를 누르면 즉시 채팅 입력란(`Quick Chat`)이 열리도록 수정합니다.

---

## 2. 배경 및 필요성
- **말풍선 유지 구분 필요**: 일시적인 미니게임 결과(주사위, 가위바위보)까지 캐릭터 머리 위에 영구적으로 남아 있으면 직접 입력한 대화 내용과 섞여 시인성이 떨어지므로, 미니게임 결과는 3초 후 사라지고 직접 입력한 채팅만 계속 떠 있도록 분리해야 합니다.
- **상단 버튼 클릭 시 포커스 해제 문제**: 상단 바의 이모트나 미니게임 버튼을 클릭하면 브라우저 포커스가 해당 버튼으로 이동하면서 캐릭터 월드 포커스가 풀려, 다시 마우스로 캐릭터 월드를 클릭해야만 방향키 이동이 가능한 불편함이 있습니다.
- **빠른 채팅 진입 편의성 강화**: 방향키로 캐릭터를 조작하다가 마우스로 버튼을 클릭할 필요 없이, 키보드 `스페이스바`를 눌러 곧바로 채팅 입력란을 띄울 수 있도록 개선하고 캐릭터 하단 안내 문구도 이에 맞춰 직관적으로 변경할 필요가 있습니다.

---

## 3. 기대 효과 / 해결 목표
1. **주사위·가위바위보 3초 후 자동 소멸 & 직접 입력 채팅만 지속 표시**:
   - 주사위·가위바위보 실행 결과는 3초(3,000ms) 동안 캐릭터 상단에 표시된 뒤 자동으로 사라집니다.
   - 직접 입력한 일반 채팅 메시지만 다음 채팅 입력 전까지 캐릭터 상단에 계속 유지됩니다.
2. **상단 버튼 클릭 시 끊김 없는 방향키 이동**:
   - 상단 이모트/미니게임/타이머 버튼 클릭 직후 자동으로 캐릭터 월드 컨테이너가 포커스되어 즉시 방향키(`↑`, `↓`, `←`, `→`)로 캐릭터를 이동할 수 있습니다.
3. **스페이스바(`Space`) 채팅 입력란 호출 및 하단 문구 변경**:
   - 내 캐릭터 하단 버튼 문구가 `스페이스바`로 표시되며, 스페이스바를 누르거나 해당 버튼을 클릭하면 즉시 채팅 입력란이 열리고 입력 포커스가 이동합니다.
