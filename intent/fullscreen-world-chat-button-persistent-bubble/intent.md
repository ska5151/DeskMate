# 작업 의도 정의서 (Intent): 우측 채팅방 제거 후 캐릭터 월드 전체 화면 확장, 닉네임 하단 채팅 입력 버튼 추가 및 말풍선 지속 유지

## 1. 작업 목적
대화방(`CHAT_ROOM`)에서 **우측 실시간 채팅방을 없애고 캐릭터 월드 화면을 전체로 꽉 채우며**, 내 캐릭터 **닉네임 하단에 `[💬 채팅 입력]` 버튼을 추가**해 클릭 시 캐릭터 더블클릭 때와 동일한 미니 채팅/액션 창이 열리도록 하고, **캐릭터 상단 말풍선이 다음 채팅을 하기 전까지 사라지지 않고 계속 유지**되도록 개선합니다.

---

## 2. 배경 및 필요성
1. **우측 실시간 채팅방 제거 및 캐릭터 월드 화면 전체 확장**:
   - 별도의 우측 채팅 목록 패널 없이, 넓고 몰입감 있는 단일 **캐릭터 월드 화면이 대화방 전체를 꽉 채우도록** 구성해야 합니다.
2. **캐릭터 닉네임 하단 `[💬 채팅 입력]` 버튼 제공**:
   - 우측 채팅방이 제거됨에 따라, 사용자가 언제든 직관적으로 대화를 입력할 수 있도록 **내 캐릭터 닉네임 바로 아래에 `💬 채팅 입력` 버튼**을 배치하고, 이를 누르면 캐릭터 더블클릭 시 나오는 빠른 채팅 입력창(이모트·미니게임·말풍선 입력)이 즉시 표시되어야 합니다.
3. **캐릭터 상단 말풍선 지속 표시 (다음 채팅 전까지 유지)**:
   - 기존에는 채팅 후 4.5초가 지나면 캐릭터 머리 위 말풍선이 자동으로 사라졌으나, 우측 채팅방 없이 캐릭터 월드 위주로 소통할 수 있도록 **해당 캐릭터가 다음 채팅을 입력하기 전까지는 말풍선이 사라지지 않고 계속 유지**되어야 합니다.

---

## 3. 기대 효과 / 해결 목표
1. **꽉 찬 캐릭터 월드 화면**:
   - 우측 채팅방이 제거되고 캐릭터 월드가 화면 전체를 넓게 사용하여 캐릭터 이동(방향키 조작)과 상호작용 공간이 극대화됩니다.
2. **직관적인 닉네임 하단 `[💬 채팅 입력]` 버튼**:
   - 내 캐릭터 닉네임 하단의 버튼을 클릭하면 즉시 빠른 채팅/액션 입력창이 열려 편리하게 말풍선 채팅과 이모트·미니게임을 사용할 수 있습니다.
3. **말풍선 상시 유지 및 다음 채팅 시 갱신**:
   - 각 캐릭터가 마지막으로 보낸 채팅 말풍선이 머리 위에 계속 남아 있어, 현재 방 참여자들이 무슨 말을 했는지 한눈에 볼 수 있으며 다음 채팅 시 새로운 말풍선으로 즉시 교체됩니다.
