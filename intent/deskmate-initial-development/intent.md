# 작업 의도 정의서 (Intent): DeskMate 초기 개발

## 1. 작업 목적 (Why)
**[windows.md](file:///C:/project/windows.md) 설계 가이드를 바탕으로 Windows 바탕화면 멀티플레이어 캐릭터 채팅 애플리케이션(DeskMate)을 구축합니다.**

단순한 창 형태의 메신저에서 벗어나, 사용자들이 로그인 후 방(Room)에 입장하면 **Windows 바탕화면 위에서 자신과 다른 유저들의 캐릭터가 돌아다니며 실시간 말풍선 대화**를 나눌 수 있는 인터랙티브 데스크톱 애플리케이션을 만드는 것이 목적입니다.

---

## 2. 배경 및 필요성 (Background & Needs)
1. **비침투적(Non-intrusive) 소셜 경험 요구**:
   - 일반 메신저나 게임은 별도의 창을 띄워 작업 공간을 차지하지만, 다른 작업을 하면서도 바탕화면 한편에서 친구·동료의 아바타와 함께 머물고 소통할 수 있는 데스크톱 메이트(Desktop Mate) 형태의 멀티플레이어 경험이 필요합니다.
2. **일반 컨트롤 UI와 투명 오버레이의 분리 필요성**:
   - 로그인, 캐릭터 선택, 방 생성/입장, 채팅 입력 등 조작이 필요한 기능은 **일반 컨트롤 창(`Main Window`)**에서 처리해야 합니다.
   - 반면 캐릭터 이동과 말풍선 출력은 바탕화면 전체를 덮되, 캐릭터가 없는 영역은 마우스 클릭이 뒤쪽 프로그램으로 투과(`Click-through`)되는 **투명 오버레이 창(`Overlay Window`)**으로 동작해야 사용자의 일상적인 PC 사용을 방해하지 않습니다.
3. **해상도 독립적인 실시간 멀티플레이 동기화 및 클라우드 DB 연동**:
   - 접속한 유저마다 모니터 해상도가 다르더라도 동일한 상대 위치에서 캐릭터가 이동하고 대화할 수 있도록, 화면 비율(`0 ~ 100%`) 기반의 실시간 Socket.io 상태 동기화 서버가 필요합니다.
   - 사용자 계정(ID/PW/닉네임) 및 최초 접속 시 선택한 캐릭터 아바타 정보(`character_type`)를 안정적으로 영구 저장하고 관리하기 위해 **Supabase (PostgreSQL)**를 데이터베이스로 도입합니다.

## 3. 핵심 작업 범위 요약 (Scope Overview)
| 구분 | 주요 구성 요소 | 설명 |
| :--- | :--- | :--- |
| **Desktop Shell** | Electron (Multi-Window & IPC) | `Main Window`(420x650 제어창)와 `Overlay Window`(전체화면 투명·항상 위·마우스 투과 창) 제어 및 IPC 브릿지(`preload.js`) 구현 |
| **Frontend** | React + Vite + TypeScript | `/#/main` (로그인 → 캐릭터 선택 → 로비/방 목록 → 채팅 컨트롤러) 및 `/#/overlay` (바탕화면 캐릭터 렌더링, 자동 배회/드래그, 말풍선 표시) 구현 |
| **Backend** | Node.js + Express + Socket.io | 사용자 인증/회원가입 및 아바타 선택 저장 API(Supabase 연동), 실시간 방 입장(`joinRoom`), 위치 동기화(`moveCharacter`), 채팅 브로드캐스트(`sendMessage`) 서버 구현 |
| **Database** | **Supabase (PostgreSQL)** | `@supabase/supabase-js` 클라이언트를 연동하여 `users` 테이블 관리 (계정 정보, 닉네임, 신규 유저 판별용 `character_type` 컬럼 영구 저장) |

## 4. 기대 효과 및 해결 목표 (Expected Outcomes & Goals)
- **완전한 멀티 윈도우 데스크톱 경험 달성**: 방 입장 시 자동으로 바탕화면 오버레이가 활성화되고, 캐릭터 위에서만 마우스 상호작용(클릭/드래그)이 활성화되며 나머지 바탕화면 영역은 기존 Windows 작업을 그대로 수행할 수 있습니다.
- **Supabase 기반의 안정적인 유저 온보딩 및 아바타 영구 저장**: 로그인 시 Supabase `users` 테이블의 `character_type === null` 여부를 판별하여 최초 캐릭터 선택 플로우를 자연스럽게 연결하고 아바타 설정을 클라우드 DB에 영구 보존합니다.
- **실시간 멀티플레이어 상호작용**: 같은 방에 입장한 유저들의 캐릭터가 바탕화면 위에서 실시간으로 배회·이동하고, 채팅 입력 시 캐릭터 머리 위에 말풍선이 즉시 표시되어 생동감 있는 커뮤니케이션을 제공합니다.
